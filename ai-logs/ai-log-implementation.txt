You *can*, but `Math.random()` can't be seeded — you get a fresh, unrepeatable sequence every run. That costs you all three benefits I just mentioned:

- **No reproducibility** — a run you liked (or one that revealed a bug) is gone forever; you can't replay it.
- **Untestable** — you can't write `expect(winner).toBe('Precinct')`, because the same input gives different output each time. You'd be reduced to loose assertions.
- **Undefensible** — in the interview you couldn't reproduce a specific playthrough to explain it.

The fix is tiny and zero-dependency — a seeded PRNG like **mulberry32** is ~5 lines:

```ts
function mulberry32(seed: number) {
  return () => {
    seed |= 0; seed = (seed + 0x6D2B79F5) | 0;
    let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

It returns a `() => number` that behaves exactly like `Math.random()` (floats in [0, 1)) — you just call `rng()` instead of `Math.random()` everywhere. Same seed in, same stream out. Same effort, but now the whole sim is reproducible and testable. No reason to use raw `Math.random()` here.
